# 🖋️ AI Typography & Character Predictor

An interactive web application that uses **Deep Learning** to predict handwritten characters and typography styles. Built with **FastAPI**, **TensorFlow**, and deployed on **Hugging Face Spaces**.

## 🚀 Live Demo
You can try the application here: 
[Link to your Hugging Face Space](https://asmaaakram2005-character-predictor-ai2.hf.space)

## ✨ Features
* **Dual Model Support:** Compare between **ANN** and **CNN** architectures.
* **Interactive Canvas:** Draw characters directly on the screen (Supports Mouse & Touch).
* **Image Upload:** Upload your own character images for prediction.
* **Real-time Analytics:** View top-5 probability distributions when the AI is uncertain.

## 🛠️ Tech Stack
* **Backend:** FastAPI (Python)
* **Frontend:** HTML5, CSS3, JavaScript
* **Deep Learning:** TensorFlow, Keras
* **Deployment:** Hugging Face Spaces / GitHub

## 📂 Project Structure
* `/css`: Application styling.
* `/js`: Drawing logic and API communication.
* `/html`: Frontend interface.
* `app.py`: FastAPI backend and model inference.
* `requirements.txt`: Project dependencies.
